4. `print`가 많은 코드: 줄이 바르게 이어 붙는가, 한글 출력이 깨지지 않는가, sleep 없는 출력 반복에서 버벅이지 않는가.
5. 일부러 `NameError`(준비 없이 `led.value(1)`) → 콘솔 빨간 Traceback `File "main.py", line N`, 코드 줄·블록 강조가 맞는 줄인가. 블록 모드에서도(함수·반복 안의 오류도).
6. OLED 블록 프로그램 "보드에 저장" → "ssd1306.py 올리는 중…" → "main.py 저장 완료" → 소프트 리셋 뒤 OLED 동작. 다시 저장하면 ssd1306.py를 또 올리지 않는가. `mfrc522_i2c.py`(큰 파일) 저장 시간.
7. 저장 뒤 `main.py`가 돌 때 멈춤 → 다음 실행이 정상인가.
8. 실행 중 USB 뽑기 → 토스트·콘솔 "보드 연결이 끊겼어요" 한 번, 배지 "끊김", 다시 연결.
9. 실행 사이에 전역 이름 공간이 남는 문제 → 실행 전 소프트 리셋을 넣을지 결정.
10. 보드에 옛 `main.py` 반복문이 돌고 있을 때 연결 → 3~6초 안에 "연결됨".
11. `for i in range(300): print(i)` → 빈 줄 없음, 순서 유지, 500행만 유지, 화면 반응.
12. 256바이트가 넘는 프로그램 실행, 올리는 중 멈춤 → 바로 다시 실행 가능.
13. 코드와 출력의 한글(`print("안녕")`).
14. 저장된 `main.py`가 도는 중에 실행/저장 → 시간 초과 토스트 없이 정상.
15. 저장 뒤 전원을 뺐다 꽂아 `main.py`가 혼자 도는가.
16. 실행 중 "끊기" → 보드가 멈추고 PyCharm에서 `>>>`가 뜨는가.
17. 탭을 닫거나 새로고침 → 포트가 풀리는가, 다시 연결되는가.
18. 저장 중 USB 뽑기 → 토스트 한 번, "끊김", 재연결 뒤 저장 정상.
19. 학원 PC(Windows Chrome, CH340/CP210x) 포트 선택과 연결 때 리셋 여부.
20. Chrome 탭 두 개가 동시에 연결 → 두 번째는 "다른 프로그램…" 토스트.

## 7. 작업 방식 기록

Task마다 구현 서브에이전트 → 리뷰 서브에이전트 → 수정 → 재검토, 계획마다 브랜치 전체 리뷰 → 수정 묶음. 리뷰에서 걸러낸 것 중 큰 것: 편집된 7세그먼트 표가 조용히 사라지던 문제, 학생 변수 이름이 장치 이름을 덮어 보드에서 죽던 문제, 코드 모드에서 줄 번호를 누르면 타이핑이 숨은 블록을 지우던 문제, 직렬 쓰기가 겹치면 예외가 나던 문제, 좁은 화면 첫 로드에서 코드 패널 자리가 빈 칸으로 남던 문제, 주석 줄이 오류 줄로 표시되던 문제.
